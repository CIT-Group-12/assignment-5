## Getting started

1. Install dependencies:
   ```
   npm install
   ```
2. Copy `.env.example` to `.env` and set `VITE_TMDB_API_KEY` to your own TMDB API key (get one at https://www.themoviedb.org/settings/api).
3. Start the dev server:
   ```
   npm run dev
   ```
